# Style guideline

> **Customize this file** with your organization's colors and chart rules. The planner copies the tokens into each plan's `## Style` section, so any executor applies them.

## Tokens (copied into every plan)
- accent: #2f6fde
- alert: #c2410c
- currency: USD

## Rules the planner applies when choosing charts
- One accent color for the primary measure, grey for context, the alert color only for what the data marks as bad (errors, churn, losses).
- Keep each category's color the same across every chart.
- KPI tiles: big number, short label, change vs the prior period when there is time data.
- Bar axes start at zero. Label units. Abbreviate large numbers (412M, 2.1K).
- No 3D, no pie charts with more than 5 slices, minimal gridlines.
- Never ask the person about chart library or styling; these rules decide it.
