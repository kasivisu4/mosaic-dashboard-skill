Any table in, a dashboard worth a second look out.

A Claude skill that plans and builds interactive one-page dashboards from CSV, Parquet, JSON, Excel or a database table. Every run designs a fresh page: its own layout, chart forms, palette and motion, where one set of marks morphs from chart to chart. Every chart passes 19 honesty rules.

Quick start

1. Install the skill

In Claude Code, add this repository as a plugin marketplace and install the planner:

/plugin marketplace add kasivisu4/mosaic-dashboard-skill
/plugin install planning-dashboard@mosaic-dashboard-skills

Or copy skills/planning-dashboard/ into your project's .claude/skills/ folder (or ~/.claude/skills/ for every project).

2. Install DuckDB for Python

pip install duckdb

3. Ask for a dashboard

Build an interactive dashboard from data/orders.parquet. I want to understand
what drives returns, for my leadership team.

The skill profiles the data, shows a short form for anything your request didn't answer (goal, page format, audience, how much to check with you), then builds the page and hands you a link and a shareable report.html.

How it works

Five steps, each saved in its own folder of the run (out/<name>/), so you can see how every decision was made.

  1. ProfileA quick look at the data in about a second, a full DuckDB profile in the background, then the model's own exploratory SQL (explore.py) until the story's angles have their numbers.
  2. IntakeA short form built from the data: what the page should help with, how it should tell the story (one-page story, dashboard grid or scrolling report), who reads it. Then a written brief: the reader, the hook, supporting questions and five concepts for the hook, one of them invented.
  3. Layout and design seeddesign_seed.py draws a fresh concept, chains of chart forms, palette, theme, icons, motion and two creative constraints, avoiding earlier runs. A confirmation card checks the data definitions with you (skipped for "just build it").
  4. PlanThe data is exported, and a plan.md is written and validated: every title a finding computed by DuckDB, every chart's visual named.
  5. Build and shareThe page is written from an empty file with Mosaic, DuckDB-WASM, D3 and d3-3d, checked (motion check, honesty pass, a critique), then bundled into one self-contained report.html.

What makes it different

Fresh design every run

A design seed picks the layout, chart chains, palette and motion, and steers away from what earlier runs used. No templates, no copied code.

Charts that morph

Every mark is drawn as polygons with the same points in every form, so one set of marks flows from stacked area to bars to 3D boxes to a heatmap.

Invented forms

Five concepts for the hook before any chart is chosen, at least one in no catalog, so lists inspire instead of limiting.

Honest by rule

Zero baselines, proportional areas, no dual axes, full periods only. A motion check and an honesty pass run before anything is shared.

Explores your data

Beyond a fixed profile, the model asks its own questions in SQL and keeps the queries and answers on record.

Explains itself

Every mark has a tooltip with exact values; every title, number and control has help text.

One file to share

report.html carries its own data: double-click it, email it, or put it on any static host. No server.

Costs and versions

Honest by rule

An unusual chart is where deception creeps in, so the skill keeps conventions of form and rules of truth apart. Conventions can be broken; these can't:

RuleWhat it prevents
Lengths and areas start at zero; areas scale with valuesBars that exaggerate a small change; bubbles that triple a doubling
One axis per measureDual-axis charts that suggest correlations
"From X to Y" uses full periods, never a peak, low or partial monthCherry-picked windows that invent a trend
Missing data is a gap; partial periods are markedInterpolated or zero-filled holes
3D only with three data axes, an orbit camera and values on hoverDecorative 3D that distorts
Animation interpolates real values; reduced motion is respected by defaultTweens that show numbers the data doesn't have

All 19 rules: references/visual-language.md.

Sharing a dashboard

One self-contained file

python scripts/bundle_report.py out/<name>

Writes 5-handoff/report.html with the data embedded. It opens by double-click with no server (it needs internet for the chart libraries). Keep it under about 15 MB by exporting pre-aggregated data.

A public gallery on GitHub Pages

python tools/build_gallery.py skills/planning-dashboard/out/<name>="Built by Claude Opus 5.5"

Copies the run into docs/gallery/ and rebuilds the gallery: live previews that play each story, filters by model, layout and skill version, and cost per run.

Costs and versions

python scripts/record_usage.py out/<name> --model claude-opus-5-5 --tokens 306115

Records model, tokens, estimated cost and skill version in 5-handoff/usage.json. Agent runs usually report one total, so cost is estimated from a typical token mix and shown with a range; pass the input/output/cache split for an exact figure. Recent runs: about $0.35 on Opus 5.5, about $0.01 on Haiku 5.5.

The skill's version lives in SKILL.md (metadata.version), each release is a git tag, and CHANGELOG.md says what changed. Compare releases with git diff v0.1.0 v0.2.0 -- skills/.

FAQ

Why don't the animations play?

Your system asks for reduced motion (on Windows: Settings › Accessibility › Visual effects › Animation effects), and the dashboards respect it by default. Turn animations on with the Motion switch on any dashboard, or the Animations switch in the gallery, which applies to all of them.

Does my data leave my machine?

No server is involved: the page runs DuckDB in your browser. The shared report.html contains the exported data, so share it only where the data may go.

Which models can run it?

Any current Claude model. The gallery has runs by Opus 5.5 and Haiku 5.5; Haiku's passed the motion check at a fraction of the cost.

Is there a template?

Deliberately not. Each page is written from an empty file for its data, guided by the method references and a fresh design seed.
